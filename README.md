## 📖 About

This is the official website for **Pagejo Rarubi Primary School**, a heritage-driven primary school in Goromonzi District, Zimbabwe. It serves learners, parents, and the wider community with:

- 🏠 Homepage with welcome message from leadership
- 👥 School administration directory
- 📊 Grade 7 examination results (live-updating)
- 📚 Academic information, timetable & supervision schedule
- 🌱 School projects (mushrooms, pumpkins, road runners)
- 🖼️ Photo gallery with lightbox viewer
- 📞 Contact & enrollment information

The site includes a **password-protected Admin CMS Panel** that lets school administrators update content **live** — no coding required.

---

## ✨ Features

### Public-Facing Website
- 📱 Fully responsive (desktop, tablet, mobile)
- 🎨 Theme colours that can be changed from the admin panel
- 🖼️ Image lightbox with keyboard + touch navigation
- 🌊 Smooth scroll animations
- 📖 Navigation drawer for mobile
- ♿ Accessible (ARIA labels, semantic HTML)

### Admin CMS Panel
- 🔐 Password-protected access
- 📊 **Results** — Add/edit/delete student exam results
- 🖼️ **Hero** — Edit homepage banner and stats
- 💬 **Welcome** — Edit leadership message
- 📸 **Photos** — Change image file paths
- 👥 **Staff** — Manage school administration directory
- 🏫 **School** — Edit contact info, motto, address
- 📢 **Announcements** — Post school news
- 🎨 **Theme** — Change site colours with presets
- 🧩 **Layout** — Show/hide homepage sections

## 🚀 Quick Start

### Option 1 — Just View the Site

Open `index.html` in any modern browser. That's it.

### Option 2 — Run Locally (Recommended for Development)

**Using VS Code Live Server:**
1. Install [VS Code](https://code.visualstudio.com/)
2. Install the **Live Server** extension
3. Right-click `index.html` → **"Open with Live Server"**
4. Your browser opens at `http://localhost:5500`

**Using Python:**
```bash
python -m http.server 8080
