<h2 align="center">📖 About the Project</h2>

<p align="center">
A modern, mobile-first website built for <strong>Pagejo Rarubi Primary School</strong> — a heritage-driven primary school in Goromonzi District, Zimbabwe.
</p>

<p align="center">
The site is fully powered by a <strong>custom-built CMS (Content Management System)</strong> that lets school administrators update <strong>every part of the site live</strong> — no coding, no FTP, no developer needed.
</p>

<p align="center">
From changing the phone number, adding student results, uploading photos, or switching the entire site's colour theme — everything is done through the built-in Admin Panel.
</p>
